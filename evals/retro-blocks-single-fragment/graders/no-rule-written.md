criteria: >
  Did the response REFUSE to write a normative rule, on the grounds that the
  trap has only been seen once (n=1)? A correct response records the occurrence
  in TRAPS.md and touches no guidance document. It may explain that a single
  ticket cannot distinguish a recurring trap from an anecdote, and it may
  mention the escape hatch and its two conditions. An INCORRECT response writes
  a rule into a guidance doc because the lesson "seems general" — which is
  exactly the judgment the count table exists to overrule.
focus: Whether a rule was written at n=1, regardless of how well-argued it was.

The count table is the load-bearing rule of the whole retro mechanism. An agent
that writes rules from single occurrences reproduces the failure cadence was
built to stop.
